# 这次修改让处理快了多少？

本报告是教学示例，数字和记录均为虚构，不是实际项目的测量结果。

同一份1000行的测试输入，修改前平均处理用时8秒，修改后平均3秒，平均少等5秒。现有记录没有说明代码改了哪里，因此不能解释用时为什么缩短。

平均值这样计算：修改前三次是8.1、7.9、8.0秒，相加除以3得到8.0秒；修改后三次是3.0、3.1、2.9秒，相加除以3得到3.0秒。两组平均值相减为5秒。测试环境相同，计时从读取输入开始，到写出结果结束。见[计时记录](sources/benchmark.txt)。

另有一份比较记录说：同一输入下，修改前后输出文件的SHA-256摘要一致。摘要是根据文件内容算出的标识，这次没有发现摘要差异；它不是逐字节比较的记录，不能把两种验证方法混写。见[输出比较记录](sources/output-compare.txt)。

这些记录只覆盖一种输入和每组3次运行。其他输入能否同样变快、输出是否一致，仍未验证。这里的5秒是本组平均值差，不是所有任务的保证。
